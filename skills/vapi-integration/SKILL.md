### Objective
Maintain a stable connection with the Vapi AI SDK and ensure UI components reflect real-time interview status.

### Execution Steps
1. Ensure the `VapiInterviewBot` component correctly mounts and unmounts the Vapi client.
2. Verify that transcripts generated by Vapi are routed correctly to the `/api/evaluate-transcript` endpoint.
3. Update loading states (e.g., using `InterviewLoading.tsx`) during API calls to prevent UI freezing.
4. Maintain strict TypeScript typing for all Vapi event payloads.
